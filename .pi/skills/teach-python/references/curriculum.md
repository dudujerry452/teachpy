# 教学顺序（严格按此推进，不跳步）

每个节点：先讲心智模型 → 落到 Python → 学员亲手实操 → 对应例题。

## 第 0 课：会用电脑的基础（前置，不碰 Python）
- 文件系统：目录、文件、路径（`references/filesystem.md`）
- 命令行：终端、命令、参数（`references/cli.md`）
- 实操：建目录 → 建 .py 文件 → cd 进去 → `python hello.py` 跑起来

## 第 1 课：顺序结构
- 名词：程序、代码、编译器、运行、打印(print)、字符串、换行
- 例题 1（打印 1）、例题 2（打印 1..5 每行一个）

## 第 2 课：分支结构
- 名词：变量、赋值、输入(input)、整数(int)、比较、条件、分支(if/else)
- 例题 3（n>5 → yes/no）

## 第 3 课：循环结构
- 名词：循环(for)、控制语句、循环体、缩进、range、累加器
- 例题 4（打印 1..n）、例题 5（1..n 累加）

## 第 4 课：循环 + 分支
- 名词：取余(%)、提前结束(break)、标志
- 例题 6（斐波那契）、例题 7（偶数）、例题 8（质数）

## 第 5 课：嵌套循环
- 名词：嵌套循环
- 例题 9（乘法表）、例题 10（三角形）

## 第 6 课：序列与综合
- 名词：列表、索引、len、随机(random)
- 例题 11（倒序）、例题 12（猜数字）

## 进度
每次会话结束，把「当前课 / 例题 / 已引入名词 / 卡点」写进 `.pi/state/progress.md`。

# 名词库（平实解释 + 配套实操）

**用法**：引入任何新名词前先查这里。没有的词条，现写一个（平实解释 + 一个让学员动手的小练习）。规则：不用高级词汇，只用心智模型。

## 第 0 课：文件系统与命令行

- **终端**：一个用「打字」和电脑对话的地方。你打一句「命令」，电脑执行、回一句结果。
  - 实操：打开终端，随便敲个字母回车，看看报错（这就是电脑没听懂）。
- **命令**：一句话，叫一个程序去做事。例如 `ls` = 「把当前目录里的东西列出来」。
  - 实操：敲 `ls`，说出你看到了什么。
- **参数**：命令后面补的说明。例如 `ls practice` = 「列出 practice 这个目录里的东西」。
  - 实操：敲 `ls` 和 `ls practice`，比较差别。
- **目录（文件夹）**：一个能装东西的盒子。盒子里可装文件，也可装别的盒子（嵌套）。
  - 实操：说出你电脑里有哪些「盒子套盒子」。
- **文件**：装内容的单元。你的代码写在 .py 文件里。
  - 实操：用编辑器新建一个 `hello.py`。
- **路径**：从一个起点走到某个文件/目录的「地址」。例如 `home/practice/hello.py` = 从家出发，进 practice 盒子，找到 hello.py。
  - 实操：说出 `hello.py` 的路径。
- **当前目录**：你现在「站」在哪个盒子里。
  - 实操：`pwd` 看自己在哪。

## 第 1 课：顺序结构

- **程序**：写好之后正在跑的那套指令。没跑起来时它只是「代码」。
  - 实操：跑一个 .py，指着屏幕说「现在是程序在跑」。
- **代码**：写在文件里、给编译器读的一行行字。
  - 实操：打开 hello.py，指出哪些是「代码」。
- **编译器**：把代码翻译成电脑能执行的动作的那个程序。它本身也是一个程序。
  - 实操：敲 `python hello.py`，说出「谁是编译器」。
- **运行**：让程序真的动起来。
  - 实操：运行 hello.py。
- **打印(print)**：让程序在屏幕上显示东西。
  - 实操：写一句 print，运行，看屏幕。
- **字符串**：一串「字」，用引号包起来（如 `"1"`）。电脑原样对待它，不算数。
  - 实操：print 一个带引号的字，再 print 一个不带引号的，看差别。
- **换行**：光标移到下一行。代码里用 `\n` 表示。
  - 实操：一句 print 里塞一个 `\n`，看输出断成几行。

## 第 2 课：分支结构

- **变量**：一个贴了名字、能装值的盒子。名字随你起，值随时可换。
  - 实操：把 5 装进叫 n 的盒子，再装 8，打印看结果。
- **赋值**：把值装进盒子。`=` 不是「等于」，是「装进去」。
  - 实操：`n = 5` 然后打印 n。
- **输入(input)**：让程序等用户敲东西进来。
  - 实操：input 拿一个数，打印它。
- **整数(int)**：没有小数点的数。input 拿到的是「字」，要用 int() 变成整数才能算大小。
  - 实操：让用户输入 7，用 int() 转换后判断它是否大于 5。
- **比较**：问两个东西谁大谁小/是否相等。结果只有「对」或「错」。
  - 实操：比较 5 和 3，说出结果。
- **条件**：一个对/错的判断，用来决定走哪条路。
  - 实操：`n > 5` 这个条件，n=7 时对，n=3 时错。
- **分支(if/else)**：「如果…就…，否则…」。条件对走 if 那条路，错走 else 那条路。
  - 实操：写一个「大于 5 说 yes，否则说 no」的小判断。

## 第 3 课：循环结构

- **循环(for)**：重复做一件事。`for` 引导「挨个取值」的过程。
  - 实操：让 1 到 5 挨个打印出来。
- **控制语句**：循环的「规则」——重复几次、什么时候停。
  - 实操：指出循环里哪句是「规则」。
- **循环体**：每次重复真正要做的事。
  - 实操：指出循环里哪几行是「每次做的事」。
- **缩进**：往右空几格。Python 用缩进告诉电脑「这几行属于哪个循环/分支」。
  - 实操：把循环体里一行删掉缩进，看报错/行为变化。
- **range**：一串挨着的整数。`range(1, 5)` = 1、2、3、4（到 5 为止，不含 5）。
  - 实操：打印 range(1,5) 里的每个数。
- **累加器**：一个「不断往里加」的盒子。先空（0），每走一步往里加一点。
  - 实操：把 1 到 5 加进盒子，最后打印盒子的值。

## 第 4 课：循环 + 分支

- **取余(%)**：算「除完剩多少」。`7 % 2` = 1。判断偶数看 `% 2` 是不是 0。
  - 实操：算 7%2、8%2，说出哪个是偶数。
- **提前结束(break)**：立刻跳出循环，不等它走完。
  - 实操：循环 1..10，一旦碰到 5 就停下。
- **标志**：一个记「是/否」的盒子。开始放「没找到」，一旦发生某件事就改掉。
  - 实操：循环 1..10，用一个标志记「有没有碰到 5」。

## 第 5 课：嵌套循环

- **嵌套循环**：循环里面再套一个循环。外层走「行」，内层走「每一行里的列」。
  - 实操：用两个循环，先打印出「行号 × 列号」的格子。

## 第 6 课：序列与综合

- **列表**：一排有编号的格子，能装一列东西。
  - 实操：建一个装 3 个数的列表，打印它。
- **索引**：格子的编号，从 0 开始。第一个 0 号、第二个 1 号…
  - 实操：打印列表里 0 号格子的东西。
- **len**：数一数「有几个」。`len(列表)` = 格子的个数。
  - 实操：打印列表的长度。
- **随机(random)**：让程序「随便挑一个」。用 random 模块的 randint 取随机数。
  - 实操：让程序打印一个 1..100 的随机数，多跑几次。

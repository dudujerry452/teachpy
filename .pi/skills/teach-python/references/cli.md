# 命令行课（前置）

目标：让学员能在终端里用命令让程序做事。

## 心智模型

- **终端**：一个用「打字」和电脑对话的地方。你打一句「命令」，电脑执行、回一句结果。
- **命令**：一句话，叫一个程序去做事。例如 `ls` = 「把当前目录里的东西列出来」。
- **参数**：命令后面补的说明。例如 `ls practice` = 「列出 practice 这个目录里的东西」。
- **运行 Python**：`python hello.py` = 叫 `python` 这个程序，去读 `hello.py` 并运行它。（接回核心心智模型：python 就是那个「编译器」）

## 必教命令（一次一个，配实操）

| 命令 | 作用 |
|---|---|
| `pwd` | 我在哪个目录 |
| `ls` | 这个目录里有什么 |
| `cd 目录` | 换个目录 |
| `mkdir 目录` | 建一个目录 |
| `python 文件.py` | 运行代码 |

## 实操序列

1. `pwd` 看自己在哪。
2. `mkdir practice` 建目录。
3. `cd practice` 进去。
4. 用编辑器建 hello.py。
5. `python hello.py` 运行。

# 文件系统课（前置）

目标：让学员能自己找到、创建、打开文件，理解「文件在哪」。

## 心智模型

- **目录（文件夹）**：一个能装东西的盒子。盒子里可以装文件，也可以装别的盒子（嵌套）。
- **文件**：装内容的单元。你的代码写在 .py 文件里。
- **路径**：从一个起点走到某个文件/目录的「地址」。例如 `home/practice/hello.py` = 从家出发，进 practice 盒子，找到 hello.py。
- **当前目录**：你现在「站」在哪个盒子里。
- **`..`**：上一层的盒子。

## 讲解要点（配实操，一次一个）

1. 目录能嵌套：盒子套盒子。
2. 路径的两种写法：从根出发（绝对）、从现在站的地方出发（相对）。
3. `..` 表示「上一层的盒子」。

## 实操序列（学员亲手做，AI 只指导不代做）

1. 用 `mkdir` 建一个目录 practice（见 cli.md）。
2. 用 `cd` 进去。
3. 用编辑器在里面建一个 hello.py。
4. 用 `pwd` + `ls` 说出 hello.py 的完整路径。
5. 说出：相对路径和绝对路径各是什么。

# 12 道例题 + 提示梯子

**本文件不含任何答案代码。** 每题只给「目标 / 新名词 / 前置 / 提示梯子」。
提示按 `hint1 → hint2 → …` 逐级变具体，但始终不给出可复制的代码。
学员卡住时**一次只给下一级**，等他再试。

---

## 1. 打印 `1`
- **目标**：让程序在屏幕上输出一个 `1`。
- **新名词**：程序、代码、编译器、运行、打印、字符串
- **前置**：第 0 课（会建 .py 文件、会用 `python 文件.py` 运行）
- hint1：程序要「在屏幕上显示出东西」，用的是一句叫 `print` 的话（print = 打印）。
- hint2：把想显示的东西放在 print 后面的括号里，再用引号包起来（`1` 在这里是「字」，不是「数」）。
- hint3：写完保存，去命令行运行这个文件，屏幕上应出现 1。

## 2. 打印 1 到 5，每行一个
- **目标**：屏幕上从上到下依次出现 1、2、3、4、5，每个占一行。
- **新名词**：换行
- **前置**：例题 1
- hint1：回忆例题 1——一句 print 显示一行。那显示 5 行需要几句？
- hint2：5 句 print，从上往下写，程序会从上往下一句句执行（这就是顺序结构）。
- hint3：（进阶）一行 print 里也能表达「换行」，符号是 `\n`（反斜杠+n），意思是「在这里换到下一行」。试试只用一句 print 显示 5 行。

## 3. 读入 n，n>5 输出 yes 否则 no
- **目标**：程序先让用户输入一个数，若这个数大于 5 就显示 yes，否则显示 no。
- **新名词**：变量、赋值、输入、整数、比较、条件、分支
- **前置**：例题 1、2
- hint1：先「拿到用户输入的数」。输入用 `input()`；input 拿到的是「字」，要当数用需 `int()` 把它变成整数。
- hint2：把这个数放进一个盒子（变量），比如叫 n。变量 = 一个贴了名字、能装值的盒子。
- hint3：分支就是「如果…就…否则…」。判断「n 是否大于 5」写作 `n > 5`。大于 5 走一条路，其余走另一条路。

## 4. 读入 n，打印 1..n 每行一个
- **目标**：输入 5 依次打印 1、2、3、4、5；输入 3 则打印 1、2、3。
- **新名词**：循环、控制语句、循环体、缩进、range
- **前置**：例题 3（已会变量、输入、print）
- hint1：要「重复打印」，用循环。循环 = 控制语句（决定重复几次）+ 循环体（每次做的事）。
- hint2：让一个数从 1 变到 n，Python 里有现成说法 `range(1, n+1)`（到 n+1 为止、不含 n+1）。`for` 引导这个「挨个取值」的过程。
- hint3：循环体是「每次取到一个数就打印它」，写在 for 下面，并且要**缩进**（往右空几格）。缩进是告诉电脑「这几行属于这个循环」。
- hint4：检查：循环体的每一行前面都空了吗？

## 5. 读入 n，求 1+…+n 并输出
- **目标**：输入 n，输出 1+2+…+n 的和。输入 5 → 15。
- **新名词**：累加器
- **前置**：例题 4
- hint1：你已经会「让一个数从 1 走到 n」。现在每走到一个数，别打印它，把它加进一个盒子。
- hint2：盒子一开始是空的（值 = 0）。每走一个数，盒子 = 盒子 + 这个数。
- hint3：循环走完后，盒子里装的就是总和。把它打印出来（打印写在循环**外面**，只打一次）。
- hint4：检查：打印那句缩进了吗？缩进了就会每次循环都打一遍——那不是你要的。

## 6. 输出斐波那契数列前 n 项
- **目标**：输入 n，依次输出前 n 项（1, 1, 2, 3, 5, 8, …）。输入 5 → 1 1 2 3 5。
- **新名词**：两个变量滚动
- **前置**：例题 5（已懂累加器）
- hint1：斐波那契规则：每一项 = 前两项之和；前两项固定是 1 和 1。
- hint2：用一个盒子装「上一个数」、一个盒子装「上上一个数」。先放 1 和 1，打印它们。
- hint3：从第 3 项起重复：新数 = 上一个 + 上上一个；打印新数；再让两个盒子各自「往前挪一格」（上上一个 ← 上一个，上一个 ← 新数）。
- hint4：「挪盒子」的顺序很关键——先算新数，再挪。先在纸上画三个盒子走一遍前 5 项，再写代码。

## 7. 打印 1..n 中的所有偶数
- **目标**：输入 n，只打印 1 到 n 里的偶数（2、4、6…）。
- **新名词**：取余、循环里套分支
- **前置**：例题 3、4
- hint1：偶数 = 能被 2 整除的数 = 除以 2 余数为 0。判断「余数是不是 0」用 `%`（取余）。
- hint2：你已经会循环（走 1..n）和分支（如果…就…）。合起来：每走到一个数，判断它是不是偶数，是才打印。
- hint3：结构是循环里套一个分支。分支写在循环体里，所以再往右缩进一层。

## 8. 判断 n 是否为质数
- **目标**：输入 n，若 n 是质数输出 prime，否则输出 not prime。质数 = 只能被 1 和它自己整除的数。
- **新名词**：提前结束、标志
- **前置**：例题 7
- hint1：思路——从 2 到 n-1 挨个试，看有没有哪个数能整除 n。有 → 不是质数。
- hint2：用一个盒子记「是否找到了能整除的数」（标志）。一开始没找到；一找到就改掉，并可立刻停下循环（提前结束）。
- hint3：循环结束后看标志：没找到 → prime；找到了 → not prime。

## 9. 打印 n×n 乘法表
- **目标**：输入 n，打印 n 行 n 列的乘法表，第 i 行第 j 列是 i×j。
- **新名词**：嵌套循环
- **前置**：例题 4
- hint1：一张表 = 很多行；每一行 = 很多个数。也就是「循环里再套一个循环」（嵌套循环）。
- hint2：外层循环负责「走每一行」（第 1 行到第 n 行）；内层循环负责「走这一行里的每一列」（第 1 列到第 n 列）。
- hint3：行号 × 列号 = 那个格子的数。每打完一行记得换行。
- hint4：两个循环的变量要用**不同的名字**，别都用 i。

## 10. 打印 n 行直角三角形（第 i 行 i 个星号）
- **目标**：输入 n，打印 n 行；第 1 行 1 个星号、第 2 行 2 个…第 n 行 n 个。
- **新名词**：嵌套循环 + 形状
- **前置**：例题 9
- hint1：第 i 行要打 i 个星号。行数从 1 到 n 是外层循环。
- hint2：内层循环负责「这一行打几个星号」——第 i 行就打 i 个，所以内层次数跟外层走到哪一行有关。
- hint3：内层每次打一个星号，但打完**不换行**（同一行的星号要连起来）；一行打完再换行。

## 11. 倒序输出一串数
- **目标**：让用户输入几个数（如 1 2 3 4 5），程序倒过来输出（5 4 3 2 1）。
- **新名词**：列表、索引、len
- **前置**：例题 4
- hint1：先把输入的数装进「一排格子」（列表）。列表 = 能装一列东西、每个有编号（索引）的盒子。
- hint2：列表格子从 0 开始编号：第一个 0 号、第二个 1 号…最后一个编号 = 总个数 - 1。
- hint3：倒着输出 = 从编号最大的格子走到编号最小的格子，每走一个打印一个。
- hint4：想知道「共有几个格子」，用 `len(列表)`。

## 12. 猜数字游戏
- **目标**：程序想一个 1..100 的数，用户反复猜；每次提示「大了/小了」，直到猜中，显示猜的次数。
- **新名词**：随机、综合
- **前置**：前面全部
- hint1：把程序拆三块：① 想一个随机数（用 random 模块的 randint）② 读用户的猜测 ③ 比较并提示。
- hint2：「反复猜直到猜中」= 循环，停止条件是「猜中了」。
- hint3：每次猜完——大了提示大了、小了提示小了、相等就结束循环。
- hint4：用另一个盒子记「猜了几次」，每猜一次加一，最后打印。

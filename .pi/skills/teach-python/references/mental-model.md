# 核心心智模型

## 模型一：代码是怎么变成程序的

**代码 → 编译器（它本身也是一个程序）→ 程序。**

- **代码**：一个文本文件，里面写着一行行的字。人写代码，是在告诉电脑「我要你做什么」。
- **编译器**：另一个程序。电脑本身**并不懂**你写的字——是编译器把你的字翻译成电脑能执行的动作。
- **程序**：翻译好之后、正在跑的那个东西。

一句话祛魅：**电脑不会自动懂你写的字，是有另一个程序在帮你翻译。** 这个「另一个程序」本身也是人写出来的普通程序。

在 Python 里，这个「另一个程序」叫 `python`。你敲 `python hello.py`，就是叫 `python` 这个程序去读 `hello.py` 这个代码文件、翻译并运行它。

> 注：严格说 Python 用的是「解释器」而非「编译器」，两者是同一类「翻译程序」的两个名字。零基础阶段记「编译器」即可，细节以后自然明白。

## 模型二：三种程序结构（所有程序语言通用）

写程序 = 把要做的事拆成下面三种结构的组合。

### 1. 顺序结构
程序从上往下一行一行地做，像读菜谱：先做第一行，再做第二行……
**默认就是这样**——你不写任何「控制」，程序就一行行往下走。

### 2. 分支结构
程序做**选择**。像走到岔路口：先看一个「条件」（一个对/错的判断），对就走一条路，错就走另一条路。
「如果 … 就 …，否则 …」。

### 3. 循环结构
程序**重复**做一件事。它由两部分组成：
- **控制语句**：重复的规则——重复多少次、什么时候停。
- **循环体**：每次重复时真正要做的那些事。

把「循环」想成：控制语句是「老板」，循环体是「打工人」；老板决定「再做一遍」，打工人就把活干一遍。
